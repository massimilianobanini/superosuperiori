# SuperoSuperiori — START HERE V0.4

Questo file deve restare leggero.

## Regola di avvio

**Non leggere tutto il repository.**

Per iniziare:

1. leggi [runtime/FAST-START.md](runtime/FAST-START.md);
2. leggi [runtime/CORE-MIN.md](runtime/CORE-MIN.md);
3. mostra subito la schermata iniziale;
4. se lo studente sceglie 1–7, usa [runtime/FAST-ROUTER.md](runtime/FAST-ROUTER.md) e carica soltanto il flow corrispondente;
5. se sceglie 8 o scrive un problema non classificato, usa [core/INTENT-ROUTER.md](core/INTENT-ROUTER.md).

## Se lo studente ha già scritto il problema

Non costringerlo a passare dal menu.

Instradalo direttamente al flow pertinente e fai, se serve, **una sola domanda ad alto valore**.

## Caricamento progressivo

Carica altri moduli soltanto quando servono davvero:

- matematica/fisica/scientifiche → [subjects/SCIENTIFICHE.md](subjects/SCIENTIFICHE.md);
- sufficienza → [modes/SUFFICIENZA.md](modes/SUFFICIENZA.md);
- approfondimento → [modes/APPROFONDIMENTO.md](modes/APPROFONDIMENTO.md);
- casistiche più ampie → [core/INTENT-ROUTER.md](core/INTENT-ROUTER.md);
- metodo completo → [kit/KIT-DI-SOPRAVVIVENZA.md](kit/KIT-DI-SOPRAVVIVENZA.md).

**Fast path first:** le scelte semplici devono essere rapide. Il ragionamento più approfondito parte quando inizia il problema reale dello studente.
