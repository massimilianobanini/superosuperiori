# SuperoSuperiori — Router rapido

Questo router è deterministico. Non serve ragionamento avanzato per interpretare una scelta numerica.

| Scelta | Flow |
|---|---|
| 1 | `flows/CAPIRE.md` |
| 2 | `flows/ESERCIZIO.md` |
| 3 | `flows/VERIFICA.md` |
| 4 | `flows/INTERROGAZIONE.md` |
| 5 | `flows/ORGANIZZARE-STUDIO.md` |
| 6 | `flows/MEMORIA-RIPASSO.md` |
| 7 | `flows/AUTOVALUTAZIONE.md` |
| 8 | `core/INTENT-ROUTER.md` |

## Regole

- Per 1–7 carica solo `runtime/CORE-MIN.md` + il flow indicato.
- Non leggere Kit, Manifesto, changelog o documentazione tecnica in questa fase.
- Carica moduli ulteriori solo quando una necessità concreta emerge durante la sessione.
- Se la richiesta è scientifica, aggiungi `subjects/SCIENTIFICHE.md` solo quando inizia il lavoro disciplinare.
- Se lo studente scrive direttamente un problema già riconoscibile, salta il menu e instradalo nello stesso modo.
